# DTAP - DNSTAP router

`DTAP` is a [DNSTAP](https://dnstap.info/) router written by Go.

`DTAP` consists of input plugins, filter plugins, and output plugins. If missing any function, you can write a plugin.

## install

```
go install github.com/mimuret/dtap/v3@latest
```
